Data saat membuka situs

Situs ini berupa halaman statis dan tidak menyediakan formulir pendaftaran atau kolom chat yang mengirim pesan ke server situs. Penyedia hosting GitHub Pages dapat memproses data teknis seperti alamat IP untuk mengoperasikan dan mengamankan layanannya, sesuai kebijakan privasi GitHub.

Tautan dan percakapan WhatsApp

Klik tombol WhatsApp membuka layanan WhatsApp dengan tujuan nomor Eza. Pesan baru terkirim setelah Anda mengirimkannya di WhatsApp. Data dan isi percakapan yang Anda bagikan digunakan untuk menanggapi pertanyaan dan mengurus pesanan; layanan WhatsApp memiliki kebijakan privasinya sendiri.

Animasi chat pada halaman hanya contoh percakapan. Tidak ada kolom pengumpulan keluhan kesehatan pada situs. Hindari mengirim informasi kesehatan rinci atau data pembayaran rahasia melalui pertanyaan produk.

Pengukuran kunjungan dan klik

Situs ini memakai Google Analytics dan Google Ads untuk mengukur kunjungan, kampanye, dan klik tombol WhatsApp. Pengukuran berjalan otomatis tanpa panel persetujuan. Personalisasi iklan tidak diaktifkan.

Google dapat menggunakan cookie atau pengenal perangkat untuk pengukuran. Data pengukuran dapat mencakup halaman yang dibuka, lokasi tombol yang diklik, serta data teknis perangkat yang diproses oleh Google. Isi percakapan WhatsApp, data kesehatan, fragment URL, dan parameter URL di luar daftar kampanye tidak dimasukkan dalam event situs. Kode dapat menyertakan utm_source, utm_medium, utm_campaign, utm_id, utm_term, utm_content, gclid, gbraid, dan wbraid. Nilai dibatasi pada format kode kampanye. Pengelola tidak boleh mengisi kode kampanye dengan data pribadi. Referrer tidak disertakan oleh adapter situs.

Anda dapat menolak atau menghapus cookie pengukuran melalui pengaturan browser, atau memakai pemblokir pelacak. Untuk permintaan terkait data Anda, hubungi kontak pada halaman ini.

Cara Google memproses data dari situs dijelaskan dalam penggunaan informasi dari situs mitra Google. Informasi layanan tersedia di kebijakan privasi Google.

Permintaan mengenai data

Untuk menanyakan atau meminta penghapusan data yang Anda bagikan langsung kepada Eza, hubungi nomor berikut dan sebutkan permintaan Anda. Penanganan mengikuti data yang dapat dikenali serta kebutuhan penyelesaian pesanan yang masih berlangsung.
